# Roadmap · AI-Native Business Workbench

[中文](./README_zh.md) · [English](./README.md)

This roadmap describes **planned milestones**, not an assertion of implemented features. Items are refined as real, reviewed code lands. No delivery dates are promised here.

## Initial public development

- Publish product-oriented English and Chinese READMEs, a capability-level roadmap and public concept diagrams.
- Bootstrap Electron/React and an independently runnable Go backend with local persistence.
- Define and test the domain-neutral microkernel contract and built-in business-plugin registration.

## First product baseline

- Desktop/Web/headless operation sharing one Go service and one governed workspace data model.
- A **Software Development** built-in plugin: workspace onboarding, project overview, engineering knowledge and memory, asset relations, change/evidence traceability, working agreements and human review.
- Optional AI assistance for source-grounded summaries and proposals, with explicit human authority and cost controls.
- Windows/Linux packaging, safe backups, workspace isolation and repeatable integration testing.

## Subsequent expansion

- Harness adapters: MCP, Skills, DeepSeekHarness, Codex and additional compatible integrations.
- Independent plugin packaging, versioned process isolation and third-party extension guidance.
- Additional business plugins based on real domain validation (e.g. content creation or manufacturing).
- Advanced deployment, collaboration and evaluation of measurable net benefits.

**Project principle:** We start with a complete Software Development experience on an industry-neutral microkernel and expand into other fields by installing domain plugins, not by forcing every workflow to imitate software engineering.

For implementation details, see actual source code and public issues/PRs as they appear. Private technical notes are intentionally not part of the public repository.
